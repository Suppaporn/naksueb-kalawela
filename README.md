# นักสืบกาลเวลา

เกมการเรียนรู้ประวัติศาสตร์สำหรับนักเรียนชั้นประถมศึกษาปีที่ 4 ในรูปแบบเกมสำรวจฉากและตอบคำถาม

## เปิดเล่น

เปิดเกมผ่าน GitHub Pages หรือเว็บเซิร์ฟเวอร์ HTTP ในเครื่อง เพราะการเชื่อม Supabase และการโหลด SDK ไม่รองรับการเปิด `index.html` แบบ `file://` อย่างเชื่อถือได้

## มีอะไรในต้นแบบ

- หน้าเข้าสู่ระบบตัวอย่าง แยกหน้าแดชบอร์ดครูและหน้าเกมนักเรียน
- แผนที่ก่อนประวัติศาสตร์ 5 ด่าน: หินเก่า หินกลาง หินใหม่ สำริด และเหล็ก
- สำรวจฉาก ค้นพบหลักฐาน อ่านสมุดหลักฐาน คุยกับไกด์ และตอบกิจกรรม 5 ข้อต่อด่าน
- คำถาม 3 รูปแบบสุ่มใช้: ทายสิ่งของจากคำบรรยาย, เลือกคำอธิบายที่มีหลักฐานรองรับ, และตอบถูก/ผิด
- ฉากทั้ง 5 ด่านใช้วิดีโอ MP4 พร้อมเสียงจากคลิป มีภาพ PNG เป็นโปสเตอร์สำรอง
- หน้าเข้าสู่ระบบและหน้าเลือกแผนที่ใช้เพลงป่าที่สังเคราะห์ด้วย Web Audio API; หน้าครูไม่มีเพลงหรือปุ่มเสียง
- หน้าด่านมีปุ่มลำโพงสำหรับเปิด/ปิดเสียงวิดีโอ ไม่มีแถบเลื่อนระดับเสียง
- ไกด์ในฉากใช้ GIF ทักทาย และหน้าต่างแชทแสดง GIF ท่าอธิบายหรือท่าคิดตามคำตอบเป็นเวลา 10 วินาที
- คำถามที่ไกด์ยังตอบไม่ได้ส่งเข้าคิวครูผ่าน Supabase; ครูเพิ่มคำตอบให้ใช้ข้ามเครื่องได้หลังรัน migration กล่องคำถาม
- หลังผ่านครบห้าด่าน มีภาพและแผนภาพข้อความสรุปเครื่องมือกับวิถีชีวิต ก่อนเข้าสมัยประวัติศาสตร์; ด่านสมัยประวัติศาสตร์ยังไม่ได้สร้าง

## ไฟล์สำคัญ

- `index.html` — หน้าเว็บและตรรกะของต้นแบบทั้งหมด
- `HANDOFF.md` — บันทึกส่งต่องานฉบับละเอียด: การตัดสินใจของโครงการ สถานะ ข้อจำกัด วิธี clone และงานที่ยังเหลือ
- `AUDIO-LICENSES.md` — ที่มาและวิธีสร้างเสียงประกอบ
- ไฟล์ PNG — ภาพพื้นหลัง ภาพแผนที่ และภาพสำรองของแต่ละฉาก ต้องอยู่โฟลเดอร์เดียวกับ `index.html`
- ไฟล์ MP4 — วิดีโอฉากและเสียงประกอบของแต่ละยุค ต้องอยู่โฟลเดอร์เดียวกับ `index.html`
- ไฟล์ GIF `guide-*.gif` — ภาพเคลื่อนไหวของไกด์ในฉากและหน้าต่างแชท
- `prehistory-summary.png` — ภาพประกอบหน้าสรุปห้ายุคก่อนประวัติศาสตร์
- `supabase-config.js` — Project URL และ Publishable key สำหรับใช้จากเบราว์เซอร์
- `supabase/` — migration ฐานข้อมูลและ Edge Function สำหรับสร้างบัญชีผู้เรียน

## ข้อจำกัดและข้อมูลเดโม

ระบบออนไลน์ใช้ Supabase Publishable key ฝั่งหน้าเว็บ บัญชีเดโมออฟไลน์ `krumhon` / `2026` และ `1111` / `1111` ใช้ได้เฉพาะเมื่อยังไม่ได้ตั้งค่า Supabase เท่านั้น ห้ามใช้รหัสเหล่านี้กับข้อมูลจริง

มีโค้ดเชื่อม Supabase สำหรับบัญชี ความคืบหน้า และคิวคำถามข้ามเครื่องแล้ว เครื่องใหม่เพียง clone repository และใช้เว็บที่เผยแพร่ ไม่ต้องสร้างฐานข้อมูลใหม่หากใช้ Supabase โปรเจกต์เดิม ดูวิธีตั้งค่าหรือซ่อมระบบใน [supabase/SETUP.md](supabase/SETUP.md) การล็อกอินนักเรียนใช้รหัสผู้เรียนกับรหัสผ่านที่ครูตั้งให้ ไม่ใช้ชื่อที่แสดง

บัญชีสาธิตเดิมในโหมดออฟไลน์เป็นตัวอย่างเท่านั้น ห้ามใช้กับข้อมูลจริงหรือเผยแพร่เป็นระบบเข้าสู่ระบบจริง ใช้รหัสผ่านครูที่แข็งแรงและไม่เก็บ Secret key หรือ Database password ใน repository สาธารณะ เนื้อหาประวัติศาสตร์ควรตรวจสอบกับหนังสือเรียน/ผู้เชี่ยวชาญก่อนใช้สอน

ดูข้อจำกัดโดยละเอียดและวิธีทำต่อจากเครื่องอื่นใน [HANDOFF.md](HANDOFF.md)
