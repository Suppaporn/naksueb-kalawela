# Audio provenance

The prototype uses no third-party music or sound recordings.

Music and ambience are synthesized in the browser at runtime with the Web Audio API in `index.html`. The jungle-adventure motif uses newly arranged oscillator notes and synthesized percussion. Wind, water, birds, insects, fire crackle, and stone tapping are generated from filtered noise and oscillator tones; there are no embedded or downloaded audio samples.

Because the project contains no external audio assets, there are no third-party audio attribution or license files required for these sounds. The audio implementation is part of this project prototype. Review this note again if recorded or downloaded sounds are added later.
